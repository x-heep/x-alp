# FPGA ZCU104: Getting Started

This guide provides step-by-step instructions to run X-ALP on the ZCU104 FPGA board. It assumes that you have already installed the tools described in [Run on FPGA](./RunOnFPGA.md).

On the ZCU104, X-ALP uses the PL DDR4 SODIMM as external DRAM: the LLC master port is connected to a DDR4 memory controller (MIG) through an AXI clock converter and an AXI width converter. Both the X-ALP clock (15 MHz) and the DDR4 reference clock are derived from the 300 MHz board clock.

---

## Hardware Connection Steps

1. **Power Up the Board**
   - Connect the power supply and turn on the board with the power switch.

2. **Connect USB**
   - Use a USB cable to connect your development machine to the USB-JTAG port of the board. Vivado uses it to program the bitstream.

3. **Connect the Programmer**
   - Connect the ESL programmer to the PMOD connectors. It provides the JTAG of X-ALP and the UART. The pinout is in `hw/target/fpga/xheep_fpga_support/constraints/zcu104/pin_assign.xdc`.
   - Connect the programmer to your development machine with a second USB cable.

---

## Programming the Board

4. **Build and Program the Bitstream**
   ```bash
   make mcu-gen
   make vivado-fpga FPGA_BOARD=zcu104
   make vivado-fpga-pgm FPGA_BOARD=zcu104
   ```

5. **Compile the App**
   Refer to the [Compile the Apps Documentation](./../How_to/CompileApps.md)
   ```bash
   make app PROJECT=hello_world TARGET=zcu104
   ```
   To run from the external DRAM, add `LINKER=dram`.

6. **Run the App**
   In three different shells:
   ```bash
   make fpga-picocom
   ```
   ```bash
   make fpga-openocd
   ```
   ```bash
   make fpga-gdb        # LINKER=spm
   make fpga-gdb-dram   # LINKER=dram
   ```
   then, in GDB:
   ```
   (gdb) load
   (gdb) continue
   ```

## LEDs and Buttons

| Signal         | Pin  | Description                                          |
|----------------|------|------------------------------------------------------|
| `rst_i`        | M11  | reset push button (active high)                      |
| `rst_led_o`    | D5   | on when X-ALP is out of reset                        |
| `clk_led_o`    | D6   | toggles about every 4.5 s                            |
| `exit_valid_o` | A5   | on when the program has returned from `main()`       |
| `exit_value_o` | B5   | bit 0 of the exit value: off for `EXIT_SUCCESS`      |

---

## Notes
- The board files are in `hw/target/fpga/xheep_fpga_support/board_files/esl_epfl_zcu104_board_files`.
- The DDR4 controller is generated by `hw/target/fpga/xheep_fpga_support/scripts/zcu104/xilinx_generate_ddr4_ctrl_wizard.tcl`. Its AXI ID width must be equal to `core_v_mcu_pkg::AxiLlcIdWidth`.
- Always make sure the bitstream and Vivado configuration match your hardware revision.
