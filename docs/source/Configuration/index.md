# Configuration

Here you can find the documentation for how to configure X-ALP. X-ALP uses the `xheep_gen` Python package (vendored from [xheep_gen](https://github.com/x-heep/xheep_gen) into `util/xheep_gen`) to model the platform and generate its files from [Mako](https://www.makotemplates.org/) `.tpl` templates. For example, `hw/system/core_v_mcu.sv.tpl` generates `hw/system/core_v_mcu.sv`.

The configuration is applied by the `mcu-gen` make target, which has to be run every time the configuration or any of the `.tpl` files change. If you have to modify a file that is generated from a `.tpl` file, modify the `.tpl` file and run `mcu-gen` to generate the new file.

The default configuration of X-ALP is generated by running:

```bash
make mcu-gen
```

If you want to modify the default configuration, check the [system configuration guide](./SystemConfiguration).
