# Linker Configuration

The linker scripts of X-ALP are in `sw/linker`. They are made of two parts:

- `common.ldh`, generated by `make mcu-gen` from `common.ldh.tpl`. It defines the memories and the base address symbols from the platform configuration;
- one hand-written script per memory layout (`spm.ld`, `dram.ld`, `rom.ld`), selected at compile time with the `LINKER` parameter of `make app` (see [Compile applications](../How_to/CompileApps.md)).

## Memories

`common.ldh` defines the following memories:

| Memory | Origin | Length | Source |
|--------|--------|--------|--------|
| `bootrom` | base of the `bootrom` peripheral | 16 KiB | peripheral domain |
| `extrom` | `0x0000_0000` | 48 KiB | fixed, inside the `debug` region |
| `spm` | start of the `llc` linker section | SPM size | [memory subsystem](./MemoryConfiguration.md) |
| `dram` | start of the `dram` linker section | `cached_size` | [memory subsystem](./MemoryConfiguration.md) |

Changing the LLC parameters in the Python configuration therefore moves and resizes the `spm` and `dram` memories of every linker script.

## Base address symbols

`common.ldh` also defines a `__base_<name>` symbol for every bus slave and peripheral, e.g. `__base_uart`, `__base_soc_ctrl`, `__base_ext_slaves`, `__base_spm` and `__base_dram`. These symbols can be used by assembly code and by the C runtime.

## Stack and global pointer

`common.ldh` sets the global pointer to the middle of the `.misc` section. Each layout script sets the stack pointer (`__stack_pointer$`) at the top of the memory it uses for data: the top of `spm` for `spm.ld` and `rom.ld`, and the top of `dram` for `dram.ld`. The boot ROM does not set up a stack, so the C runtime (`sw/device/lib/crt/crt0.S`) loads it from this symbol.

## Memory layouts

| Script | `.text` | `.misc` (rodata, data, sdata) | `.bss` | `.bulk` |
|--------|---------|-------------------------------|--------|---------|
| `spm.ld` | `spm` | `spm` | `spm` | `spm` |
| `dram.ld` | `dram` | `dram` | `dram` | `dram` |
| `rom.ld` | in `.misc` | `spm`, loaded at `extrom` | `spm` | in `.misc` |

The `.bulk` section can be used to place large buffers with `__attribute__((section(".bulk")))`.

## Adding a custom layout

To add a layout, create a new script in `sw/linker` that includes `common.ldh` and places the sections in the available memories, then add it to the `LINKER` selection in `sw/CMakeLists.txt`. Keep in mind that the Verilator testbench only preloads images linked into `spm` or `dram`, chosen from the suffix of the ELF file name (`main.<LINKER>.elf`).

To add a memory, add a linker section to the memory subsystem in the Python configuration and a matching entry in `sw/linker/common.ldh.tpl`.
